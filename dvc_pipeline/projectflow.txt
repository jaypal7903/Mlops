Building pipeline :
1. create a local repo and clone it in local repo (Add Experiments).
2. Add src folder along with all components(run  them individually).
3. add data directories to .gitignore file
4. Now git add, commit and push

setting up dvc pipeline (without params)
5. create dvc.yaml file and add stages to it.
6. dvc init then "dvc repro" to test the pipeline automation. (check dvc dag)
7. Now git add, commit, push

setting up dvc pipeline (with params)
8. add params.yaml file.
9. add the params setup
10. Do "dv repro" again to test the pipeline along with all params
11. Now git add, commit and push

Experiments with dvc 
12. pip install dvclive
13. add the dvclive code block in model evaluation.
14. Do "dvc exp run" it will create a new dvc.yaml (if already not there) and the dvclive directory (each run will be consider as an experiment by DVC)
15. Do "dvc exp show" on terminal to see the experiments or use extension on vsCode (install dvc extension)
16. Do "dvc exp remove {exp-name}" to remove exp (optional) | "dvc exp apply {exp-name}" to reproduce previous experiment
17. change params, re run code (produce new experiments)
18. git add, commit and push

Adding a remote s3 storege to DVC:
19. Logging to AWS consol
20. Create IAM user (straight forward process)
21. create s3 (enter unique name and create)
22. pip install dvc[s3]
23. pip install awscli
24. aws configure (run on terminal)  -> To connect your command line tools to your Amazon Web Services account
25.dvc remote add -d dvcstore s3://bucketname  (dvcstore is only name written any name)
26.dvc commit - push the exp outcome that you want to keep
27.Finally git add, commit and push

Extra :
- Remove/ delete aws resources beacause it take charge
- Adding stage to dvc.yaml: "dvc stage add -n data_ingestion -d src/data_ingestion.py -o data/raw python src/data_ingestion.py"
  where,
  - -n is stage name
  - -d is deps
  - -o is outs
  - -p is params
